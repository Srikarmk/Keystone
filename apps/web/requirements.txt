# The analysis engine, installed straight from this repository.
#
# The package lives in services/core, outside this directory, and a Vercel build only
# uploads the project root — so it cannot be imported by a relative path. Installing it
# from git is the alternative to vendoring a copy here, which would drift from the
# real one the moment either changed.
#
# Pinned to a branch rather than a tag on purpose: the parser and the site are
# developed together, and a function running a month-old parser against a dossier
# shape the reader no longer understands is a worse failure than a rebuild.
keystone-core @ git+https://github.com/Srikarmk/Keystone.git@main#subdirectory=services/core
